# PORTOFOLIO_MUHAMMAD_IRSYAD

Web portofolio statis (HTML, CSS, JavaScript murni, tanpa build).

## Struktur
- `index.html`  : isi dan struktur halaman (teks, foto, link)
- `style.css`   : semua tampilan dan warna
- `script.js`   : animasi, loading, tab, mode edit, form kontak
- `images/`     : semua foto dan logo

## Cara pakai
- Lokal: buka `index.html` di browser.
- Ganti foto/logo: timpa file di `images/` dengan nama yang sama.
- Ganti email tujuan form: ubah `EMAIL` di baris awal `script.js`.
- Ganti teks: edit langsung di `index.html`.

## Deploy
- GitHub Pages: upload semua file ke repository, lalu Settings > Pages > Deploy from a branch > main / root.
- Vercel: import repository dari GitHub, Framework Preset "Other", lalu Deploy.
